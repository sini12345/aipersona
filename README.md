# AI Persona Traeningsplatform

Interaktiv traeningsplatform for social- og specialpaedagogik studerende.

## Funktioner

- **5 realistiske personas** med autentiske kommunikationsstile
- **5 paedagogiske teorier** som valgfri ramme for feedback
- **AI-drevet feedback** baseret pa samtaleanalyse
- **Professionelt design** med intuitiv brugerflade

## Teorier

- Anerkendelse (Honneth, Schibbye, Bae)
- Empowerment (Adams, Andersen, Mik-Meyer)
- Low Arousal (Elvén, McDonnell)
- Mentalisering (Fonagy, Allen, Bateman)
- Neuropædagogik (Fredens, Thybo, Gade)

## Brug

1. Vælg en persona
2. Vælg evt. en teoretisk ramme
3. Angiv din Anthropic API-nøgle
4. Start samtalen og øv dig
5. Afslut og modtag feedback
